# 桁架结构有限元分析程序（直接刚度法）

## 项目简介

本项目实现了一维杆单元和二维桁架单元的直接刚度法有限元求解器。程序采用 Python + NumPy 编写，支持 JSON 格式输入，能够自动生成对号矩阵（LM），直接组装总体刚度矩阵，通过缩减法处理位移边界条件，求解节点位移、约束反力，并计算各单元应力与轴力。

**主要功能**

* 一维杆单元（1D bar）和二维桁架单元（2D truss）分析
* 自动生成对号矩阵 LM
* 总体刚度矩阵直接组装
* 位移边界条件缩减法处理
* 输出节点位移、约束反力、单元应力、轴力
